# 🔑 Password Generator & Strength Checker

A Python-based cybersecurity tool that generates secure passwords and evaluates password strength based on industry-standard security practices.

The application allows users to create strong random passwords and analyze existing passwords to identify weaknesses and improve security.

## 🚀 Features

* Quick Password Generation
* Custom Password Generation
* Password Strength Analysis
* Uppercase Letter Support
* Lowercase Letter Support
* Numeric Character Support
* Special Character Support
* Secure Random Password Generation using Python's `secrets` module
* Password Security Recommendations
* Input Validation
* Menu-Driven Command Line Interface

## 🛠 Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* Secrets Module
* String Module
* System Module (sys)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Soheetpatil/Password-Generator-Strength-Checker.git
```

Navigate to the project directory:

```bash
cd Password-Generator-Strength-Checker
```

## ▶️ Run the Program

```bash
python main.py
```

| Numbers            | Yes    |

* 🟡 Medium
* 🔴 Weak
